# Dictado Libre
Dictado por voz gratis para Windows (local con faster-whisper u online con Groq).

Al dictar aparece una pastilla abajo en el centro, con la onda de la voz. La configuración, el historial y las métricas se abren desde el ícono junto al reloj.

En Escritura se elige el tono según el programa, el atajo de comando y Ayudame a escribir. Con una clave gratis de Groq el texto queda mejor; sin clave, se acomoda en la computadora.

En Palabras están el diccionario (nombres, siglas, jerga) y los fragmentos de voz. El modo susurro, en Micrófono, sirve para hablar bajito. Privacidad, en General, deja el audio y el texto en esta computadora.

Publicar versión: `git tag v1.3.0 && git push --tags` → GitHub Actions compila `DictadoLibre-Setup.exe` y la app se actualiza sola encima de la instalación anterior.
